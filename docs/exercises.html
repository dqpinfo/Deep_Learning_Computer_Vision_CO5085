Dữ liệu dùng chung

Nhóm dùng MNIST xuyên suốt E1–E3: chữ số viết tay 0–9, ảnh xám 28×28, 10 lớp, 60.000 ảnh train và 10.000 ảnh test. Tập nhỏ, huấn luyện được trên CPU, giúp nhóm tập trung vào phần cài đặt mô hình.

E2 · tập con

E3 · sắp tới

Dùng lại MNIST, so sánh LSTM/GRU với MLP/CNN của E1.

E1

Softmax, MLP và CNN cho phân loại ảnh

Việc cần làm

  • Softmax: làm phẳng ảnh thành vector, một lớp tuyến tính rồi softmax
  • MLP: vẫn dùng vector phẳng, thêm nhiều tầng ẩn có hàm kích hoạt
  • CNN: tích chập + pooling (có thể thêm batch norm) và head phân loại
  • Huấn luyện bằng loop tự viết, đánh giá trên validation/test

Cách so sánh

  • Độ chính xác của từng mô hình
  • Số tham số / dung lượng mô hình
  • Đường cong loss và accuracy theo epoch
  • Phân tích lỗiConfusion matrix và một số mẫu bị đoán sai
Kết quả trên 10.000 ảnh test: Softmax 91,08% · MLP 96,97% · CNN 98,91%. CNN có ít tham số hơn MLP (105.962 so với 109.386) nhưng chỉ sai 109 ảnh so với 303 ảnh của MLP.

E2

Self-attention nhiều đầu và các kiểu token hoá ảnh

Việc cần làm

  • Tự cài MSA từ phép toán cơ bảnLinear, nhân ma trận/einsum, softmax, ghép các head — không dùng nn.MultiheadAttention
  • Một bản MSA dùng module có sẵn của PyTorch để đối chiếu
  • Lắp MSA vào bộ phân loại nhỏEncoder nông + head; có thể thêm LayerNorm, FFN, positional encoding
  • Thử tối thiểu 2 (nên 3) cách tạo token

Các kiểu token

  • Patch theo lưới, có thể kèm token CLS
  • Pixel hoặc từng hàng ảnh làm một token
  • CNN-stem: mỗi vị trí trên feature map là một token

Cách so sánh

  • MSA tự cài vs. MSA của PyTorch trên cùng kiểu token
  • Giữa các kiểu token: accuracy, thời gian, nhận xét
Kết quả trên 10.000 ảnh test: token theo hàng 88,2–88,5%, token theo patch 86,2–86,7%. MSA tự viết cho đầu ra trùng khớp với nn.MultiheadAttention khi dùng chung trọng số.

E3

Xem ảnh như một chuỗi: LSTM và GRU

Việc cần làm

  • Cài cả LSTM lẫn GRU (được dùng nn.LSTM / nn.GRU)
  • Chọn cách biến ảnh thành chuỗiMỗi hàng/cột là một bước thời gian, hoặc chuỗi các patch/block
  • Thử ít nhất hai cách biểu diễn, hoặc LSTM vs. GRU trên cùng một cách

Cách so sánh

  • Đối chiếu với baseline không hồi quy (MLP/CNN của E1, cùng split)
  • Accuracy và số tham số
  • Khả năng nắm bắt phụ thuộc theo chuỗi so với CNN/MLP
